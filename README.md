# Echo Protocol

Echo Protocol is a browser-based psychological voice recognition trial.

## Features

- Hard Mode
- Error Mode
- 120 Voice Recognition Questions
- Dynamic Dialogue System
- Multiple Ending Archives
- Persistent Save System
- Full Audio Settings
- Voice Acting
- Progressive Unlocks

## Controls

- Mouse
- Fullscreen supported

## Version

v1.0.0

## Browser Support

- Google Chrome (Recommended)
- Microsoft Edge
- Mozilla Firefox
